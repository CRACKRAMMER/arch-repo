Transport Security Note / 安全说明

This repository is currently served over HTTPS without a repository GPG key (SigLevel = Optional TrustAll). Once the maintainer adds ARCH_GPG_PRIVATE_KEY to GitHub Actions secrets, signed packages and crackrammer.gpg will be published here automatically.

1. Add Repository to /etc/pacman.conf / 添加软件源

[crackrammer]
SigLevel = Optional TrustAll
Server = https://crackrammer.github.io/arch-repo/arch/$arch

2. Install or Upgrade with Pacman / 安装与更新

# Desktop client (Tauri v2 + Go sidecar)
sudo pacman -Syu prismray

# Headless Web server + systemd user unit (optional)
sudo pacman -Syu prismray-server
